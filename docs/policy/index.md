# Политики проекта

> Type: Policy. Здесь собраны правила проекта и ссылки на подробные политики.

Политики обязательны для разработчиков, ревьюеров и агентов, вносящих изменения в репозиторий. Они помогают сохранить предсказуемое поведение SDK, воспроизводимую сборку, устойчивый публичный API и контролируемое развитие кода без случайных изменений.

SDK предназначен для рабочих приложений и зависит от контрактов T-Invest API, сгенерированного кода и сборки в `dist`. Правила распространяются на изменения кода, тестов, скриптов, зависимостей, документации и архитектуры, включая инструмент тестирования и процесс работы с proto.

## Когда читать этот раздел

Читайте применимые политики перед изменениями и при ревью. Если допустимость правки вызывает сомнения, начните с правила принятия решений и политики внесения изменений.
